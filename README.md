# 한눈 (캘린더 · 가계부 · 메모) 설치 파일

## 최신 판 받기

**https://github.com/KimJeongok/hannun-release/releases/latest/download/hannun.apk**

폰의 크롬에서 위 링크를 누르면 hannun.apk가 내려받아져요. 새 판이 나와도 같은 링크예요.

## 처음 설치

1. 위 링크로 받은 hannun.apk를 열어요 (알림 창 또는 내 파일 › 다운로드).
2. '이 출처의 앱 설치 허용'이 나오면 허용을 켜고 뒤로 가요.
3. [설치]를 눌러요. 'Play 프로텍트: 안전하지 않은 앱' 창이 나오면 [세부정보 더보기] → [무시하고 설치]. '앱 검사를 위해 보내시겠습니까?'는 [보내지 않고 설치].
4. 압축(.zip)하지 마세요. 압축했다 푼 파일은 '악성 앱으로 의심'으로 막혀요.
5. Play 프로텍트 '앱 검사'는 끄지 마세요.

## 새 판으로 업데이트

같은 링크로 받아 열고 [업데이트]를 눌러요. 앱을 지우지 마세요 (지우면 기록이 사라져요).

## 알아 두기

이 저장소에는 설치 파일과 이 안내만 있어요. 한눈의 기록은 각자 폰 안에만 저장되고 어디로도 보내지 않아요.

결제 알림 불러오기를 쓰려면 앱 안에서 알림 접근을 허용해요. 막히면 폰 설정 › 애플리케이션 › 한눈 › ⋮ › '제한된 설정 허용'.

자세한 사용법: 앱 › 앱 설정 › 기능 설명서
